# Photography assets

Drop your photos here as `01.jpg … 06.jpg` (or any names), then edit the
`PHOTOS` array in `lib/data.ts` to match each filename + caption + EXIF.

Tips:
- Keep them web-sized (long edge ~1600px, JPG ~80% quality) so the page stays fast.
- Cards render at a 4:3 crop; landscape shots look best.
- Add or remove entries in `PHOTOS` freely — the grid, ⌘K, file tree, and the
  "compiled · N frames" count all follow the array length automatically.
